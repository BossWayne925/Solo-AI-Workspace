> **ICM Layer 2: Memory.** This file is small on purpose. It loads on **every**

> line. Put the detail in the linked files, never here.

## Files
- **voice.md** — how your content should sound: voice words, do/don't, real samples. *Read before writing anything (Stage 03/04).*
- **published.md** — log of what's gone out, so nothing gets repeated and threads can be continued.
- **what-worked.md** — performance notes; what landed and why. *Read before planning a week (Stage 02).*
- **session-log.md** — one line per completed stage pass. The audit trail.
