# Stage 03 — Create

> **ICM Layer 4: Context.** Your role for this stage. Read `../CLAUDE.md` first.

**Job:** turn one planned idea into a finished draft — a video script, post,
newsletter, or thread — that sounds like the user, not like an AI.

## Input
- **`../02_plan/output/week-plan.md`** — start with the anchor piece (or the piece the human names).

## Read
- **`../memory/voice.md` — first, always.** Absorb the voice words, the do/don't list, and the reference samples before writing a line.
- `../profile.md` — the audience (write to that one person) and the offer (so the CTA points somewhere real).

## Do
1. Confirm the **format and platform** if not obvious — a YouTube script, an X thread, and a newsletter are shaped completely differently.
2. Generate **3 hook options**, then write the body using the chosen one (or your best pick, stated as such).
3. Structure by format:
   - **Video script:** Hook (first 5s) → promise → meat in clear beats → recap → one CTA. Written to be spoken.
   - **Short/Reel:** one idea, hook-first, under ~150 words.
   - **Post/thread:** sharpest line first, one idea per line, no windup.
   - **Newsletter:** subject + preview → personal open → one idea → one CTA.

Quality bar:
- **Voice match over everything.** Re-read against `voice.md`; fix any banned word or broken "don't" before showing the human.
- Open with tension, a claim, or a question — never "In this video we're going to…".
- Specifics over adjectives. One idea fully landed beats five half-covered.
- Self-check: *"If the user read this cold, would they believe they wrote it?"* If not, it's not done.

## Output
Write the finished draft to **`output/<slug>.md`** (e.g. `output/case-study-first-line.md`).
This is the input to Stage 04.

## Close the pass
1. Append to `../memory/session-log.md`: `<date> — 03_create — drafted: <title>`.
2. Show the human the draft and say the next stage is **04_repurpose**. Stop for review.
