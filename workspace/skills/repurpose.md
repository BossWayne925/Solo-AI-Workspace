# Skill: repurpose

**Use when:** you have one finished piece and want to turn it into many — the
highest-leverage move for a solo creator. One anchor → a week of content.

**Reads:** `profile.md` (platforms), `memory/voice.md` (always), `memory/published.md`

---

## What to do

1. Read `memory/voice.md` — every variant still has to sound like you.
2. Read `profile.md` for which platforms matter and in what priority.
3. Take the source piece (a video script, a long post, a newsletter — whatever's
   finished).
4. Pull out the **reusable units** first: the core claim, the 3–5 key points, the
   best one-liners, any story or example, the data points.
5. Reshape those units into platform-native formats. Don't just trim — **re-form**:

   - **Short / Reel script:** the single sharpest point, hook-first, under ~150 words.
   - **X / LinkedIn post:** lead with the strongest one-liner; one idea; native length.
   - **Thread:** the key points as a sequence, each line standing alone.
   - **Newsletter blurb:** personal framing + the one idea + link back to the anchor.
   - **Carousel / slides:** one point per slide, punchy.
   - **Caption / title + description:** for the anchor itself.

6. Aim for **one anchor → 5–8 derivatives.** Label each with its platform.

## Quality bar
- Each variant must **stand on its own.** Someone who never saw the anchor should
  get full value — no "as I said in my video."
- Match each platform's native shape, not a generic crosspost. A short is not a
  trimmed video; a thread is not a chopped-up essay.
- Keep the voice consistent across all of them (re-check against `voice.md`).
- Vary the hooks — don't open all eight pieces the same way.
