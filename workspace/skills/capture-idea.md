# Skill: capture-idea

**Use when:** you have a raw thought, a build log, a screenshot, a voice-memo
transcript — anything unprocessed — and you want it turned into a usable content idea.

**Reads:** `profile.md` (pillars, audience)

---

## What to do

1. Read `profile.md` for the content pillars and who the audience is.
2. Take the raw input the user gives you. Don't make them format it — accept mess.
3. For each distinct idea you find in it, produce a captured idea:

```
### <punchy working title>
- **Pillar:** <which of the user's pillars it fits, or "new pillar?">
- **Angle:** <the specific take — one sentence, not a topic>
- **Why it'd land:** <what tension or curiosity it creates for the audience>
- **Format fit:** <video | short | post | newsletter | thread> and why
- **Hook seed:** <one possible opening line>
```

4. If a raw dump contains several ideas, split them. One vague topic is worth less
   than three sharp angles.
5. End by asking: *"Want me to plan these into a week (`plan-week`), or write one
   now (`write-piece`)?"*

## Quality bar
- An "idea" is an **angle**, not a topic. "AI tools" is a topic. "The one AI tool
  I deleted after a week and what I use instead" is an angle.
- Tie every idea back to the audience's actual situation from `profile.md`.
- If the input is too thin to make a real angle, say so and ask one sharpening
  question rather than inventing filler.

## Where it goes
Captured ideas can live wherever the user keeps their backlog (a notes app, a file,
a doc). This skill doesn't write to memory — ideas only earn a place in
`published.md` once they ship.
