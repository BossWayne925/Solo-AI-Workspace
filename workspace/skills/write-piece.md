# Skill: write-piece

**Use when:** you have one idea and want a finished draft — a video script, a post,
a newsletter, a thread — that sounds like you.

**Reads:** `profile.md` (audience, offer, platform), `memory/voice.md` (always)

---

## What to do

1. **Read `memory/voice.md` first.** This is non-negotiable. Absorb the voice words,
   the do/don't list, and the reference samples before writing a single line.
2. Read `profile.md` for the audience (write to that one person) and the offer
   (so the call-to-action points somewhere real).
3. Confirm the **format and platform** with the user if not obvious. A YouTube
   script, an X thread, and a newsletter are shaped completely differently.
4. Draft the piece. Structure depends on format:

   - **Video script:** Hook (first 5 seconds — earn the next 30) → promise → the
     meat in clear beats → recap → one CTA. Write spoken, not written.
   - **Short / Reel:** One idea. Hook in the first line. Under ~150 words. End on a
     loop or a button.
   - **Post / thread:** Lead with the sharpest line. One idea per line/tweet. No windup.
   - **Newsletter:** Subject line + preview → personal open → one main idea → one CTA.

5. **Generate 3 hook options** for the opening, then write the body using the one
   the user picks (or your best pick, stated as such).

## Quality bar — this is where the skill earns its keep
- **Voice match over everything.** Re-read the draft against `voice.md`. If it uses
  a banned word or breaks a "don't," fix it before showing the user.
- Open with tension, a claim, or a question. **Never** a windup like "In this video
  we're going to…".
- Specifics over adjectives. Real numbers, real examples, real names of tools.
- One idea, fully landed, beats five ideas half-covered.
- Match the rhythm of the reference samples — sentence length, paragraph breaks,
  how the user actually talks.

## Self-check before delivering
Ask yourself: *"If the user read this cold, would they believe they wrote it?"* If
not, it's not done. Then offer to run `repurpose` to spin it into other formats.
