# Stage 04 — Repurpose

> **ICM Layer 4: Context.** Your role for this stage. Read `../CLAUDE.md` first.

**Job:** turn one finished piece into many — the highest-leverage move for a solo
creator. One anchor → a week of platform-native content.

## Input
- **`../03_create/output/<slug>.md`** — the finished anchor piece from Stage 03.

## Read
- **`../memory/voice.md` — always.** Every variant still has to sound like the user.
- `../profile.md` — which platforms matter, and in what priority.

## Do
1. Pull out the **reusable units** from the anchor first: the core claim, the 3–5
   key points, the best one-liners, any story/example, the data points.
2. Re-form (don't just trim) those units into platform-native formats:
   - **Short/Reel script** — the single sharpest point, hook-first, under ~150 words.
   - **X / LinkedIn post** — strongest one-liner first, one idea, native length.
   - **Thread** — key points as a sequence, each line standing alone.
   - **Newsletter blurb** — personal framing + the one idea + link back to the anchor.
   - **Carousel** — one point per slide.
   - **Title + description** — for the anchor itself.
3. Aim for **one anchor → 5–8 derivatives.** Label each with its platform.

Quality bar:
- Each variant **stands on its own** — no "as I said in my video."
- Match each platform's native shape; a short is not a trimmed video.
- Vary the hooks — don't open all eight the same way. Re-check voice.

## Output
Write all variants to **`output/variants.md`**, grouped by platform. Stage 05 logs what actually ships.

## Close the pass
1. Append to `../memory/session-log.md`: `<date> — 04_repurpose — N variants from <title>`.
2. Show the human the variants and say the next stage is **05_review** (after things go live). Stop for review.
