# Foundation (Gemini)

The rules for this workspace live in **`CLAUDE.md`** and apply to any AI agent,
including you.

**Read `CLAUDE.md` now and follow it exactly.** It defines the Interpretable
Context Methodology (ICM) this workspace runs on: the 5-layer stack, working one
numbered stage at a time, keeping context windows small, passing each stage's
output to the next, and stopping for human review at every transition.

(Kept as a separate file because Gemini loads `GEMINI.md` by convention. The
content is intentionally identical to the Claude foundation — one source of truth.)
